Staffwright — your small team's AI staff

An open-source, self-hosted workstation: DSH engine · SQLite knowledge base · shared long-term memory · token-gated gateway · dual-protocol MCP (streamable-http + classic). No accounts — a static access token is the only gate.

🚀 Open Workbench 📚 Documentation
🛡️

Token gate

Every MCP endpoint and gateway API sits behind a static access token (Bearer / X-DDW-Token); missing or invalid means 401. Tools are filtered through whitelist tiers — commercial plugin tools never register.

🔌

Dual-protocol MCP

streamable-http (2025-03-26) and the classic endpoint (2024-11-05) run side by side with an identical toolset; FastMCP rebuilds after plugins load, so plugin tools are real implementations.

📚

Knowledge base + memory

A personal-grade SQLite knowledge base (FTS5/LIKE retrieval) plus lightweight long-term memory, reachable from both REST APIs and MCP tools; degrades gracefully on offline or storage faults and never blocks the main flow.

📱

Phone-ready PWA

Open the workbench in any mobile browser, then add it to your home screen; the token stays in the local session and never travels inside iframes.

🔁

Plugin framework

PluginBase loader with a hot-reload runtime; the plugin directory ships whitelisted components only (ddw-docs-portal / ddw-searxng) and extends freely.

♻️

License hygiene

DSH (MIT) and every bundled component (Apache-2.0 / MIT / BSD / SQLite public domain) fully declared; zero GPL, zero commercial components.
